## About

I'm Dragon, a student developer. I learn by building — and I'll keep learning that way for a while.

Most of what I make starts as a problem I actually had: a Linux setup that wasn't right, a security workflow that had too many tools and not enough sense, an idea I couldn't stop thinking about.

I'm not building a startup. I'm not building a product. I'm a student with a laptop, too much curiosity, and a stubborn streak.

When I write code, I reach for **Python, C, Bash, and HTML** — enough to get close to the metal without a framework in the way.

My default setting is simple: **privacy should be the default**.

When I'm not in a terminal, it's probably sketching, watching anime, playing games, or down a rabbit hole in some piece of tech I didn't know I needed.

## Currently Building

### Copper Linux

Copper Linux is my main project right now — the thing I spend most of my free time on.

It's a Linux distribution built from source, started on the 21st of September, by me. Small team, mostly me. It's a work in progress: not production ready, but usable and fun to play with.

What's being built:

- A first boot that ends in a shell prompt; desktops are opt-in.
- Persistence design, via a labelled COPPER volume.
- The `ingot` package manager.

```
sudo bash iso/build.sh
```
